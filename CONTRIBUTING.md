# Contributing

Start with AGENTS.md and PLAN.md. Keep changes small and supported by a concrete failure
or a clearly scoped capability. Preserve resident autonomy and record the difference
between observations, hypotheses and scripted fixtures.

Use Python 3.12+, uv and isolated PostgreSQL. Run Ruff and the relevant offline tests.
Never submit credentials, company material, private conversations, raw live traces or
production dumps. Mock inference is the default and CI must never call paid models.

Describe the concrete before/after behavior and validation in each pull request.
Do not claim social emergence or model reliability from a small synthetic test.
Contributions must be yours to contribute under the project's Apache-2.0 license.
